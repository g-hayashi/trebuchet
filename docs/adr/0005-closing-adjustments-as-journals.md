# ADR 0005: 家事按分と少額減価償却を決算整理の仕訳として登録する

- 状態: 採用
- 日付: 2026-10-20
- 関連: specs/003-tax-return/research.md R4, R5, R6, R7、[ADR 0012](0012-multi-year-depreciation.md)（複数年の償却。定額法などを足した）

## 状況

青色申告決算書（003）では、地代家賃などの家事按分と、少額減価償却資産の償却を反映する。001 は「帳票は仕訳から導出する」（Constitution I）ため、決算書の損益計算書・貸借対照表は帳簿と一致していなければならない。

決算書の出力だけで按分後・償却後の金額にすると、帳簿の損益計算書・貸借対照表と決算書が食い違い、事業主貸の残高も合わなくなる。

## 決定

按分の振替（事業主貸 / 費用の科目）と、少額減価償却（減価償却費 / 工具器具備品、家事分は 事業主貸 / 減価償却費）は、ドメインが仕訳の案（`JournalDraft`）を作り、利用者が内容を確かめてから 001 の `createJournal` で登録する。

- 日付は年度末日
- `journals.source` は `manual` のまま変えない。作った元は新しい表 `adjustment_journal_refs`（仕訳 ID、種別 `home_use` | `depreciation`、按分の登録 ID または資産 ID）で持つ
- 案の登録（仕訳と参照）は 1 つのトランザクションで行う。失敗したときは、どちらも残さない
- 按分の対象の金額は、対象の科目（補助科目）の年間の借方−貸方から、按分の振替の仕訳（`adjustment_journal_refs` の `home_use`）の行を除いた額
- 登録済みの振替と、いまの帳簿から計算した期待値に差があるときは警告（`HOME_USE_ADJUSTMENT_STALE`）と、差額の仕訳の案を出す（R6）

## 理由

- 決算書、帳簿の損益計算書・貸借対照表、事業主貸の残高が、同じ仕訳から導出されて一致する（Constitution I）
- `journals.source` は CHECK つきの列挙で、値を足すにはテーブルの作り直しが要る。参照の表を足すだけで済む（Constitution VII）
- 締め済みの年度の仕訳は 001 の訂正の規則（ADR 0003）に従う。決算整理の仕訳も同じ監査・訂正の仕組みに乗る
- 利用者が案を確かめてから登録するため、按分率や資産の変更が勝手に帳簿を書き換えない

## 検討した代替案

- 決算書の出力だけで按分後の金額にする: 帳簿の損益計算書・貸借対照表と決算書が食い違い、事業主貸の残高も合わない
- `journals.source` に値（例: `adjustment`）を足す: CHECK つきの列挙のため、テーブルの作り直しが要る

## 影響

- 按分・償却の仕訳は、通常の仕訳と同じように仕訳帳・総勘定元帳・試算表に現れる。区別は `adjustment_journal_refs` で行う
- 按分率や資産を後から変えたときは、警告と差額の案で直す。古い仕訳は、001 の訂正の規則に従って訂正する
- 償却の方法は、003 では少額の特例（`small_asset_28_2`）だけだった。009 で `method` の列挙に定額法（`straight_line`）と一括償却（`lump_sum`）を足し、`depreciate` を方法で分けた（R7、ADR 0012）。開業費も同じ案の経路で仕訳にする
- 既存の仕訳（取り込んだ帳簿で取得がすでに費用になっているもの）に資産を結びつけた場合は、仕訳の案を作らず、3 ページの表にだけ載せる
