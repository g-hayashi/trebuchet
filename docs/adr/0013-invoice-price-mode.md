# ADR 0013: 請求の価格計算と帳簿の消費税区分を分ける

- 状態: 採用
- 日付: 2026-11-02
- 関連: 005/R27、[ADR 0008](0008-invoice-journal-linkage.md)

## 状況

税込単価だけを扱う従来の「税抜と消費税を別記」は、加算の設定と区別しにくい。免税を理由に内訳を消す実装も、合意した消費税相当額を請求する操作を妨げていた。

## 決定

入力方式 `priceMode` を税込/税抜で選び、内訳表示 `taxDisplay` と分ける。明細の金額は入力方式のまま写し、税抜入力では税率ごとの小計に一度だけ消費税相当額を加算する。方式・請求税率は発行時に固定する。

免税の場合も請求税率を選べるが、帳簿では加算後の全額を対象外の売上とする。免税の写しに登録番号を載せない。課税時は請求税率と計上日の帳簿の税区分の税率を一致させる。

## 結果

30時間×税抜6,000円、10%の場合、請求額と売掛金・売上高はいずれも198,000円となる。免税の仕訳税額は0。発行済みの請求書は変更せず、取消と再発行で訂正する。
