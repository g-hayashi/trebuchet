# ADR 0012: 複数年の償却は資産の属性から計算し、開業費だけ年度の決定を保存する

- 状態: 採用
- 日付: 2026-11-01
- 関連: specs/009-depreciation-deferred/research.md R5, R6, R7, R8, R12、[ADR 0005](0005-closing-adjustments-as-journals.md)

## 状況

003 の償却は少額減価償却資産の特例だけで、取得の年に全額を償却するため、年度をまたぐ計算がなかった。009 で定額法・一括償却資産・開業費を足すと、各年度の償却費が前の年度までの償却に依存する。ADR 0005 のとおり償却は決算整理の仕訳として登録するが、各年度の額を「資産の属性から計算する」か「登録した仕訳から積み上げる」かを決める必要がある。開業費は任意償却で、年度ごとの額を利用者が決める。

## 決定

- 定額法・一括償却資産の各年度の償却費は、資産の属性（取得価額、方法、耐用年数と償却率、供用日、前年までの累計とその年、除却日）と税制の値だけから計算する純関数で求め、保存しない。登録した仕訳の金額は計算に使わない
- 開業費は、年度ごとの償却額の決定（0 円を含む）を `deferred_amortizations` に保存する。期首の未償却残高は、前の年度までの決定のうち、結びついた仕訳が取り消されていないものを差し引いて求める
- 年度ごとの仕訳との結びつきは、003 の `adjustment_journal_refs`（年度の列を持つ）を使い、種別 `deferred_amortization` と列 `deferred_asset_id` を足す。同じ（出所, 年度）の有効な仕訳は高々 1 件で、確定のトランザクションの中で作り直して判定する
- 定額法の除却の年度は、月割りの償却と、残りの未償却残高を 1 つの仕訳の案にする。除却の種類（`disposal_kind`）が廃棄なら残高を除却損（家事分は事業主貸）、売却なら事業主貸へ振り替える（譲渡所得の計算は範囲外。利用者の判断 2026-11-01）
- 登録済みの償却の仕訳がある資産・開業費は、計算に効く項目を変えられない（仕訳を取り消してから変える）

## 理由

- 個人の減価償却は強制償却で、登録を忘れた年度の分も償却したものとして残高が減る。仕訳から積み上げると、忘れた年度の後の残高が法令とずれ、取消・訂正のたびに以後の年度が動く。忘れた年度は、期首の帳簿残高と台帳の照合（009 FR-020）と欄 18 の照合で見つかる
- 開業費の年度の額は利用者の判断で、帳簿の集計値ではない（Constitution I が禁じる集計値の保存に当たらない）。0 円の決定（償却しないと決めたこと）は仕訳を作らないので、保存しないと記録できない
- 結びつきの表を新しく作ると、出所が `adjustment_journal_refs` と 2 か所に分かれる。取消の後の再登録で UNIQUE 制約が邪魔になる
- 償却と除却損を 1 つの案にすれば、「同じ資産・同じ年度の案は 1 回」の判定が 1 つで済み、片方だけの登録が起きない
- 計算に効く項目の変更を許して差額の案を出す方法（按分の `HOME_USE_ADJUSTMENT_STALE`）は、複数の年度と締め済みの年度にまたがり規則が増える

## 検討した代替案

- 各年度の償却費を、前の年度に登録した仕訳から積み上げる: 強制償却と合わない
- 開業費も目安（60 か月の均等）で自動に計算する: 任意償却（所得税法施行令 137 条 3 項）を表せない
- 年度ごとの結びつきの新しい表（資産, 年度 → 仕訳、UNIQUE）: 上の理由で採らない
- 償却と除却損を別の案（別の種別）にする: 種別と判定が増える
- 売却を扱わず知らせるだけにする: 売却を除却として登録すると未償却残高が除却損（必要経費）になり誤る
- アプリの前の年度（取込済み）の償却の仕訳を、定額法の資産に年度ごとに結びつける: 結びつけの誤りを直す仕組みが要る（参照の行は消せない）。前年までの累計とその年（`prior_through_year`）で、翌年度から台帳で計算する

## 影響

- `depreciate` は税制の値（償却率の表など）を受け取り、方法で計算を分ける（ADR 0005 の「影響」が定めた足し方）。結果は `Result`（税制の値がなければ計算しない）
- 台帳の計算を始める年度は `prior_through_year + 1`（なければ供用の年）。アプリの前の年度（freee から取り込んだ年度）の償却は台帳で計算しない
- 003 の `saveFixedAsset` に変更の制限（409 `DEPRECIATION_JOURNAL_EXISTS`）が加わる。少額の特例の資産にも効く
- `fixed_assets`・`adjustment_journal_refs`・`tax_parameters`・`closing_audit_log` は CHECK の列挙を変えるため作り直す（マイグレーション `0011`。トリガーは `0012` で作り直す）
