# ADR 0015: 源泉徴収税額は入金の時点で事業主貸に計上する

- 状態: 採用
- 日付: 2026-11-07
- 関連: 013/R1〜R3・R6、[ADR 0008](0008-invoice-journal-linkage.md)、[ADR 0013](0013-invoice-price-mode.md)

## 状況

報酬から所得税を差し引いて支払う取引先には、請求書に源泉徴収税額と差引請求額を載せる。実際に差し引かれる額は取引先の計算で決まり、入金まで分からない。差し引かれた分を売掛金から消し込まないと売掛金が残り続ける。振込手数料と取り違えると経費になる。

## 決定

- 源泉徴収税額は入金の消し込みの時点で、借方 事業主貸（3090）に計上する。所得税は事業主個人の税のため、期末の振替は要らない。入金の仕訳は、借方 入金先・事業主貸（税額）、貸方 売掛金（入金額 + 差額 + 税額）の 1 件
- 発行の仕訳は源泉徴収の有無にかかわらず、売掛金／売上高を合計の額で 1 件だけ登録する（ADR 0008 のまま）
- 請求書の源泉徴収の対象額は、消費税相当額を区分して表示する（`taxDisplay = separate`）ときは税抜、それ以外は合計。税額は対象額のうち境目（100 万円）以下に低い率、超える部分に高い率を掛け、1 円未満を切り捨てる（整数だけで計算する）
- 率と境目は `tax_parameters` に適用期間と出典つきで持ち、発行日の値を使う。2026 年分までは国税庁タックスアンサー No.2795（10.21%・20.42%）、2027〜2047 年分は防衛特別所得税の源泉徴収の Q&A で、合計の率は据え置き（確度 medium。本文は読めず二次情報で確かめた）。該当する期間がなければ発行を拒む（`WITHHOLDING_RATE_MISSING`）
- 法人の事業体は範囲外。法人が受け取る報酬は原則として源泉徴収されず、差し引かれた所得税（利子・配当など）は仮払税金などで受けて法人税から控除するため、法人テナントを作るときに別に決める
- 対象かどうかは取引先が決めるので、アプリは判定せず、取引先ごとの「源泉徴収あり」の設定に従う

## 理由

- 実際に差し引かれる額は入金で決まり、請求書の値と違うことがある。入金の時点で計上すれば、利用者が直した額で売掛金を 0 にできる
- 発行の仕訳を変えないので、005 の請求・取消・消し込みの規則（`JOURNAL_LINKED`、`PAYMENT_EXCEEDS_BALANCE`）がそのまま効く
- 申告書の源泉徴収税額の欄は、実際に差し引かれた額を入金日の年で数える

## 検討した代替案

- 発行時に源泉徴収税額を計上し、売掛金を差引額にする: 取引先の計算の違いを直せない
- 仮払税金などの科目で受ける: 個人の所得税は事業主個人の税で、期末の振替が要らない事業主貸が合う
- 税率を「％」の小数で持つ: 浮動小数になり、金額は整数という原則に反する

## 影響

- 入金の消し込みに源泉徴収税額の欄を足し、充当額は入金額 + 差額 + 源泉徴収税額になる
- 年間の一覧は、入金日がその暦年の、取り消されていない消し込みの源泉徴収税額を取引先ごとに集計する（帳簿の事業主貸の行と一致する。INV-75）
- 2038 年以降の源泉徴収の税制の値は足していない。年に 1 回 `seed/` を見直すときに足す
