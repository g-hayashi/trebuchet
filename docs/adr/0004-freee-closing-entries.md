# ADR 0004: freee の年初付の決算振替を期首残高に繰り込む

- 状態: 採用
- 日付: 2026-10-19
- 関連: specs/002-freee-import/research.md R5, R6, R7

## 状況

freee の仕訳帳には、前年分の決算振替が、会計期間の開始日（例: 2025-01-01）の仕訳として入っている（事業主借→元入金、損益→元入金、元入金→事業主貸）。freee の総勘定元帳の前期繰越は、この振替の前の値になる。

001 の期首残高は、決算書の期首の貸借対照表と同じ「振替の後」の値である。001 は損益を仕訳から導出するため、「損益」科目を持たない。期首残高と振替の両方を取り込むと二重になる。

## 決定

「決算整理仕訳 = 1 かつ 日付が会計期間の開始日」の仕訳を、前年分の決算振替と判定する。

- 仕訳の取込では、既定で取込対象外（`PRIOR_YEAR_CLOSING`）にする。利用者は対象に含められるが、「損益」科目は帳簿に対応する科目がないため、含めると取込不可になる
- 期首残高の案と元帳との照合では、この振替を期首に繰り込む

## 理由

- 001 の期首残高（振替の後）の規則を変えずに済む
- 決算書の期首の貸借対照表と、取り込んだ期首残高が一致する
- 期首残高と振替の二重計上を避けられる

## 検討した代替案

- 振替を仕訳として取り込み、期首残高を振替の前の値にする: 期首の貸借対照表が決算書と合わず、「損益」科目が必要になる

## 例（合成の値）

前期繰越が 元入金 1,000、事業主借 100、事業主貸 300、資産 1,400（事業主貸を除く）、前年の利益 600 のとき（借方 1,700 ＝ 貸方 1,100 ＋ 利益 600）、振替は次の3つ。

- 事業主借 100 / 元入金 100
- 損益 600 / 元入金 600
- 元入金 300 / 事業主貸 300

期首残高の案は 元入金 1,400、事業主借 0、事業主貸 0、資産 1,400 となり、貸借が一致する。

## 影響

- 取込のプレビューでは、年初付の振替が「取込対象外（前年分の決算振替）」に出る
- 期首残高の案（`packages/domain/src/import/freee/opening.ts`）と照合（`reconcile.ts`）は、判定（`closing.ts`）に該当する行を元帳から繰り込む。「損益」は捨てる
- 元帳の開始行の合計は貸借がずれる（前年の利益の分）。振替を繰り込むと一致する
- 前年度の帳簿の繰越との差は FR-020a の警告で確かめる
