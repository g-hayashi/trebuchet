# Quickstart: 源泉徴収と仮払税金（013）の確かめ方

## 自動の検査（サンドボックスで実行できる）

```sh
pnpm vitest run --project domain   # INV-73〜75 の性質テスト、計算の具体例
pnpm vitest run --project db       # 列・CHECK・トリガー、tax_parameters の一致
pnpm vitest run --project server   # contracts §1〜4
pnpm vitest run --project web      # 取引先・請求書・入金・年間の一覧の画面
pnpm typecheck && pnpm lint && pnpm test && pnpm manual:check
```

計算の具体例（spec の例と同じ。テストに入れる）:

| 合計 | 表示 | 対象額 | 源泉徴収税額 | 差引請求額 |
|---|---|---|---|---|
| 330,000（税抜 300,000） | 別記 | 300,000 | 30,630 | 299,370 |
| 1,205,000 | 税込のみ | 1,205,000 | 143,961 | 1,061,039 |
| 1,000,000 | 税込のみ | 1,000,000 | 102,100 | 897,900 |

## 利用者の端末での確認（`pnpm dev`）

1. 取引先の請求の条件で「源泉徴収あり」にする
2. 合計 1,205,000 円の請求書を作り、案と印刷の画面に「源泉徴収税額 143,961」「差引請求額 1,061,039」が出ることを見る。発行して仕訳が売掛金／売上高 1,205,000 円の 1 件であることを見る
3. 入金 1,061,039 円を消し込む。源泉徴収税額の欄に 143,961 円が最初から入っていること、仕訳が 普通預金 1,061,039・事業主貸 143,961 ／ 売掛金 1,205,000 で、請求書が「入金済み」になることを見る
4. 年間の源泉徴収の一覧で、その取引先の源泉徴収税額が 143,961 円であることを見る。消し込みを取り消すと一覧から消えることを見る
5. 「源泉徴収なし」の取引先の請求書に源泉徴収の行が出ないことを見る
