# Quickstart: 画面の作り直し（011）の検証

## 1. 自動の検証（サンドボックスで実行できる）

```sh
pnpm typecheck && pnpm lint && pnpm test
pnpm --filter @trebuchet/web build   # routeTree.gen.ts の再生成（ルートの増減の後）
```

確かめること:

- INV-69〜72 の性質テスト（data-model §4）が通る。
- `apps/server/test/auth-coverage.test.ts`（INV-29）が新しいルート（contracts/http-api.md §1）を網羅し、未サインインで 401。
- 消した API（申告の控え・評価）が 404。
- web のテスト: ヘッダー・メニュー（contracts/ui-shell.md §1・§2）、ホームの件数と 0 件の表示・項目ごとの失敗（§3）、かんたん入力の 2 行の送信、Enter の移動、一覧の Sheet、明細のステップと 1 件ずつの確認、証憑の複数の追加、請求の発行済みの表示、科目の保護の表示。

## 2. 利用者の端末で行う（サーバーを起動する）

```sh
pnpm --filter @trebuchet/web e2e     # 既存 5 本 + mobile.spec.ts（390 px、SC-010）
pnpm bench:reports                   # GET /home が約 500 仕訳で 2 秒以内（SC-003）
pnpm eval:statements                 # 仕訳の入力の場面を足す前と後で比べる（憲法 IV、R19）
pnpm dev                             # 下の手動の確認
```
