## 2. 手動での確認（利用者の端末）

```bash
TREBUCHET_DATA_DIR="$PWD/.tmp/quickstart-005" pnpm dev    # http://localhost:5173
```

パスキーの登録の後、合成の事業体（個人、免税・税込）を作り、合成の取引先を3つ（時間単価型・月額定額型・条件なし）作る。

1. **設定（US4）**: 請求書の設定 → 発行者の情報（合成の氏名・住所・連絡先・振込先）、消費税の表示「税込のみ」、次の通し番号 `43` → 保存。発行済みの最大の番号以下には戻せない（手順 4 の発行の後に、`43` 以下を入れて拒否されることを確かめる）
2. **条件（US4）**: 時間単価型の取引先に単価・支払期限「翌月 10 日」、月額定額型に月額・「翌月末」、敬称を設定。単価に 0 や小数を入れると保存できない
3. **工数と案（US1）**: 工数の画面で対象月の時間単価型に `120.5` を入れる（`1.25` は拒否）→ 請求書の案 → 明細「{対象月}分 {品名} 120.5 時間 × 単価」と、支払期限が翌月 10 日。月額定額型は工数なしで月額の案。案で明細を足す・直す（最大5行）と合計が変わる
4. **発行（US1, US4）**: 発行 → 番号の末尾が `043`、次は `044`。仕訳の一覧に借方 売掛金・貸方 売上高（取引先つき、対象月の末日付）が1件。仕訳から請求書へ、請求書から仕訳へたどれる。その仕訳を仕訳の画面から訂正・取消しようとすると拒否される
5. **重複の警告（US1）**: 同じ取引先・同じ月の案に警告が出る。確認すれば発行できる
6. **印刷（US1, SC-005）**: 請求書 → 印刷 → 「PDF に保存」。既定のファイル名に請求番号が入り、A4 1枚に収まり、宛名・敬称・発行者・番号・発行日・期限・明細・合計・振込先が載る。設定を「別記」に変えても、免税の期間の請求書は消費税額を載せない（課税の期間を設定した事業体では、税抜の小計・税率ごとの税額・税込の合計が載る）
7. **消し込み（US2）**: 1件を全額、1件を差額（合成の手数料の額）を「振込手数料」として消し込む → どちらも「入金済み」、2件目の仕訳は普通預金・支払手数料／売掛金の複合仕訳。別の請求書に一部だけ入金 → 「一部入金」と残額。残額を超える額は拒否
8. **期限切れ（US2）**: 支払期限が過去になる対象月で発行した未入金の請求書が、一覧で「期限切れ」と分かる。取引先ごとの未回収の合計が出る
9. **取消（US1, US2）**: 入金のある請求書の取消は拒否 → 消し込みを理由つきで取り消す → 請求書を理由つきで取り消す → 「取消」になり、番号は飛んだまま。次の発行は次の番号
10. **定期仕訳（US3）**: 毎月 25 日・合成の金額・借方 地代家賃・貸方 普通預金、開始を 2 か月前の月で保存 → 登録される件数の確認が出る → 確認すると、過去の各月 25 日付の仕訳が登録され、画面の上部に自動で登録した件数が出る。server を再起動しても増えない。予定日「末日」は 2 月なら 28 日（または 29 日）付。停止 → 再開で、停止の間の月は登録されない（再開の月に今日以前の回があれば、登録される件数の確認が出る）
11. **登録できない回（US3）**: 開始月を締め済みの年度の月にした定義は、その回が「登録できない」と示され、「この回は登録しない」で消せる

## 3. 時間の目安（SC-001, SC-006）

- 合成の取引先 8 社で、工数の入力 → 案の確認 → 発行 → PDF の保存を通して、15 分以内に終わるかを計る
- 1 か月分の請求と入金の管理を、今の請求書のサービスを使わずに終えられるかを、利用者が実際の月末に確かめる（結果の金額・件数はリポジトリに書かない）
