## 2. 手動での確認（フィクスチャ）

```bash
TREBUCHET_DATA_DIR="$PWD/.tmp/quickstart-002" pnpm dev   # http://127.0.0.1:5173
```

1. **準備**: 事業体を名称「取込テスト」・種別「個人」・開始年度「2025」で作成する
2. **仕訳の取込（US1）**: メニューの「取込」→「freee から取り込む」でフィクスチャの仕訳帳を選ぶ → 件数・期間・借方と貸方の合計・対応表が表示され、帳簿はまだ変わらない（「仕訳」の一覧は空）。年初付の決算振替は「取込対象外（前年分の決算振替）」に出る
3. **対応表（US1）**: 「事務用品費」などの未定の行で科目を選び「対応表を保存」→ 未定がなくなると「取り込む」が押せる。「取り込む」→「N件の仕訳を取り込みました」と表示され、仕訳の一覧に複合仕訳が1仕訳として並ぶ
4. **二重登録の防止（US1）**: 同じファイルをもう一度選ぶ → すべて「取込済み」で、「取り込む」が押せない
5. **期首残高（US2）**: 「会計期間」→ 2025年度の「期首残高」→「freee の元帳から読み込む」でフィクスチャの元帳を選ぶ → 決算振替を繰り込んだ案が表示され、マイナスの開始残高に警告が出る → 「保存する」
6. **照合（US3）**: 「取込」→「元帳と照合」で 2025年度とフィクスチャの元帳を選ぶ → すべての科目が「一致」
7. **取消（US4）**: 取込の履歴から手順3の取込を開き、1件の仕訳を訂正してから「取込を取り消す」→ 訂正済みの件数の確認 → 理由を入れて取り消す → 仕訳の一覧と試算表から消え、照合は「不一致」になる。同じファイルを選ぶと再び「新規」になる
8. **差分の取込（US5）**: 取り込み直した後、フィクスチャの「追加・変更・削除あり」の版の仕訳帳を選ぶ → 追加分だけが新規、変更・削除は警告に出て、帳簿の仕訳は変わらない

確認が終わったら `pnpm dev` を止め、`.tmp/quickstart-002/` を削除する。

## 3. 実データでの照合（ローカル専用）

`work/` の実データで SC-003・SC-004（001 の SC-008）を確かめる。出力はリポジトリに含めない。

```bash
node scripts/verify-freee-import.ts \
  --journal work/<2025年分の仕訳帳>.csv \
  --ledger  work/<2025年分の総勘定元帳>.csv \
  --year 2025
```

1. ヘッダの照合（research R3）で、必須の列がすべて見つかる。メモタグの区切り文字を確かめる（R4）
2. 照合がすべての科目で一致する（SC-003）
3. 出力された PL・BS の科目別の金額を、2025年分の青色申告決算書（R7）と見比べ、すべて一致する（SC-004）
4. 2026年分（途中経過）でも同じ手順で取り込み、FR-020a の警告（前年度の繰越との差）が出ないことを確かめる
