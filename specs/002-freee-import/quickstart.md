## 2. 手動での確認（フィクスチャ）

```bash
TREBUCHET_DATA_DIR="$PWD/.tmp/quickstart-002" pnpm dev   # http://127.0.0.1:5173
```

1. **準備**: 事業体を名称「取込テスト」・種別「個人」・開始年度「2025」で作成する
2. **仕訳の取込（US1）**: メニューの「取込」→「新しい取込」で「仕訳帳のファイル」にフィクスチャの仕訳帳（`journal-2025.csv`）を選ぶ → プレビューに期間・件数（新規 14件、取込済み 0件、対象外 1件、取込不可 0件、警告 1件）・借方と貸方の合計・対応表が表示され、帳簿はまだ変わらない（「仕訳」の一覧は空）。年初付の決算振替は判定「対象外」（理由「前年の決算整理（期首残高に反映済み）」）に出る
3. **対応表（US1）**: フィクスチャの科目はすべて「案」が入る（「事務用品費」→消耗品費、「交際費」→接待交際費など）。内容を確かめ、必要なら科目を選び直して「対応表を保存」→ 状態が「保存済み」になる。「取り込む」→「14件の仕訳を取り込みました。」と表示され、仕訳の一覧に複合仕訳が1仕訳として並ぶ
4. **二重登録の防止（US1）**: 同じファイルをもう一度選ぶ → 14件が「取込済み」、決算振替は「対象外」のまま、「新しく取り込む仕訳はありません。」と表示され、「取り込む」が押せない
5. **期首残高（US2）**: 「会計期間」→ 2025年度の「期首残高」→「freee の元帳から読み込む」で「総勘定元帳のファイル」にフィクスチャの元帳（`ledger-2025.csv`）を選ぶ → 決算振替を繰り込んだ案（6行、借方合計・貸方合計とも 1,070,000 円）が入力欄に入り、警告「「売掛金」の期首残高がマイナス（▲20,000円）のため、貸方の残高にしました」が出る → 「保存する」→「保存しました。」
6. **照合（US3）**: 「取込」→「元帳と照合」で年度「2025」とフィクスチャの元帳を選ぶ → 「すべての科目が一致しました。」と表示され、すべての科目が「一致」
7. **取消（US4）**: 仕訳の一覧から1件（例: No.14）を開き、「訂正する」→ 摘要やメモを直して「訂正を保存」→ 理由を入れて「訂正を確定」。次に「取込」の履歴で手順3の取込（ファイル名のリンク）を開き、「取込を取り消す」→ 理由を入れて「取消を確定」→「取込の後に訂正された仕訳が1件あります。」と件数が示される → 「訂正済みの仕訳を含めて取り消す」→「14件の仕訳を取り消しました。」。仕訳の一覧は空になり、試算表の借方・貸方の合計は 0 になり、照合は「一致しない科目が14件あります。」（「不一致」）になる。同じファイルを選ぶと再び新規 14件になる
8. **差分の取込（US5）**: 手順7の後に同じ仕訳帳をもう一度「取り込む」（14件）。続けて「追加・変更・削除あり」の版（`journal-2025-v2.csv`）を選ぶ → 新規は追加分の2件だけ（取込済み 13件）。「freee 側で変更あり（1件）」と「freee 側で削除（1件）」が変更前後の内容つきで出て、帳簿の仕訳は変わらない。「取り込む」で2件だけ登録される（仕訳の合計 16件）

確認が終わったら `pnpm dev` を止め、`.tmp/quickstart-002/` を削除する。

## 3. 実データでの照合（ローカル専用）

`work/` の実データで SC-003・SC-004（001 の SC-008）を確かめる。出力はリポジトリに含めない。

```bash
node scripts/verify-freee-import.ts \
  --journal work/<2025年分の仕訳帳>.csv \
  --ledger  work/<2025年分の総勘定元帳>.csv \
  --year 2025 [--mapping .tmp/<対応表>.json] [--keep]
```

使い捨ての事業体を `.tmp/verify-freee/` に作り、取込 → 元帳からの期首残高の保存 → 照合 → PL・BS の科目別の金額を標準出力に出す（フラグの詳細はスクリプトの先頭のコメント）。対応が未定の科目が残ると一覧を出して止まる（終了コード 1）ので、`--mapping` の JSON（`.tmp/` の下に置く。ImportMappingsPut と同じ形で、科目は `accountName` でも指定できる）を渡して再実行する。2026年分は、2025年分を `--keep` で実行したあとに `--continue --year 2026 --journal … --ledger …` で足す。

1. ヘッダの照合（research R3）で、必須の列がすべて見つかる。メモタグの区切り文字を確かめる（R4）
2. 照合がすべての科目で一致する（SC-003）
3. 出力された PL・BS の科目別の金額を、2025年分の青色申告決算書（R7）と見比べ、すべて一致する（SC-004）
4. 2026年分（途中経過）でも同じ手順で取り込み、FR-020a の警告（前年度の繰越との差）が出ないことを確かめる
