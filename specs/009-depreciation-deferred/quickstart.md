## 2. 手動での確認（合成のデータ）

```bash
TREBUCHET_DATA_DIR="$PWD/.tmp/quickstart-009" pnpm dev   # http://localhost:5173
```

1. **準備**: 事業体を種別「個人」・開始年度「2026」で作る。2026 年度の期首残高に、工具器具備品 180,000（借方）、開業費 255,000（借方）、元入金 435,000（貸方）を入れる。2026 年の仕訳を 2 件入れる: 2026-07-10 借方 工具器具備品 / 貸方 事業主借 1,000,000（機材A・B）、2026-12-20 借方 一括償却資産 / 貸方 事業主借 150,000
2. **定額法（US1 シナリオ1・2）**: 固定資産台帳（`?year=2026`）で、方法「定額法」・機材A・取得日と供用日 2026-07-10・500,000 円・耐用年数 4・事業専用割合 100% を登録 → 償却費 62,500、未償却残高 437,500（償却率 0.250・本年中の償却期間 6/12 は決算整理の案と決算書の 3 ページに出る）。同じ内容で機材B を事業専用割合 60% で登録 → 必要経費算入額 37,500。耐用年数 1 で登録 → `USEFUL_LIFE_UNSUPPORTED` で拒否される
3. **前年までの累計（US1 シナリオ4）**: 機材C・取得日 2024-01-15・300,000 円・耐用年数 5・前年までの累計 120,000（2025 年分まで）を登録 → 2026 年の償却費 60,000（12/12）、期首 180,000、期末 120,000
4. **一括償却（US2）**: 方法「一括償却資産」・取得日 2026-12-20・150,000 円 → 2026 年 50,000（月割りしない）。同じ入力を 250,000 円にすると `LUMP_SUM_COST_OUT_OF_RANGE` で拒否される（少額の特例の年間の上限の集計から外れることは domain のテストで確かめる）
5. **除却（US1 シナリオ6・7）**: 機材B を除却の日 2026-10-05・種類「廃棄」で除却する → 決算整理の案は 償却 41,667（7〜10 月の 4/12）、必要経費算入額 25,000、除却損 458,333（うち事業分 274,999、家事分 183,334）の 1 つの仕訳になる（借方 減価償却費 41,667 / 貸方 工具器具備品 41,667、借方 事業主貸 16,667 / 貸方 減価償却費 16,667、借方 固定資産除却損 458,333 / 貸方 工具器具備品 458,333、借方 事業主貸 183,334 / 貸方 固定資産除却損 183,334）。売却の確認は自動テストで行う（同じ資産を種類「売却」で除却すると、除却損の 2 行の代わりに 借方 事業主貸 / 貸方 工具器具備品 458,333 になり、譲渡所得は範囲外である旨が出る）
6. **開業費（US3）**: 繰延資産の欄で、開業費・開業日 2025-04-01・総額 300,000・前年までの累計 45,000（2025 年分まで）・勘定「開業費」を登録 → 2026 年の目安 60,000、上限 255,000。255,001 を入れる → 拒否される。0 を入れる → 案は作られず「償却しない」と記録され、決算書の「償却を検討してください」の警告が出ない。60,000 に直す → 案（借方 減価償却費 / 貸方 開業費 60,000）が出る
7. **案の登録と決算書（SC-003）**: 決算整理の案をすべて登録する（機材A・B・C、一括償却、開業費の 5 件）→ 案は「登録する仕訳の案はありません。」になる。決算書の 3 ページの「減価償却費の計算」に 5 行（定額法 3、一括償却 1、任意償却 1）が載り、必要経費算入額の合計 257,500 が欄 18 と一致し、`DEPRECIATION_MISMATCH` の警告がない。1 ページの任意欄に「固定資産除却損」274,999。「一致しません」系の警告が出ない
8. **照合（US1 シナリオ5、US3 シナリオ5）**: 2026 年度の期首残高の工具器具備品を 200,000 に変える（元入金も 455,000 に）→ 警告「工具器具備品の期首残高（200,000 円）が、減価償却の台帳の期首の未償却残高（180,000 円）と一致しません（差 20,000 円）」。戻すと消える
9. **変更の制限（Edge Cases）**: 機材A の取得価額を変えようとする → 409 `DEPRECIATION_JOURNAL_EXISTS`（2026 年の償却の仕訳を取り消してから）。名称は変えられる。仕訳帳で機材A の償却の仕訳を取り消す → 案が再び出る
10. **締め（FR-021）**: 2026 年度を締める → 案の一覧に償却・開業費の案が出ない
11. **出力**: CSV の 3 ページの行に償却率・本年中の償却期間が入り、画面と一致する

確認が終わったら `pnpm dev` を止め、`.tmp/quickstart-009/` を削除する。

## 3. 実データでの確認（ローカル専用）

実データの帳簿で、登録した資産・開業費の期首の未償却残高の合計が期首の帳簿残高と一致すること（`ASSET_REGISTER_MISMATCH` が出ないこと）を、利用者の端末で確かめる。資産名・金額・按分率はリポジトリに書かない。結果は「一致・不一致」と警告の件数だけを控える。
