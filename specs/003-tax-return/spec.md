# Feature Specification: 決算処理と確定申告の支援（青色申告決算書の作成）

**Feature Branch**: `003-tax-return`

**Created**: 2026-10-19

**Status**: Draft

**Input**: User description: "003 決算処理・確定申告支援（個人事業主の青色申告決算書の作成）"（001 の帳簿・締め・帳票と 002 の freee 取込を前提に、家事按分・少額減価償却資産・青色申告特別控除を反映した青色申告決算書（一般用）の各欄の値を作り、利用者が e-Tax へ転記できるようにする。あわせて、申告に使う事業所得以外の金額と書類の保管場所を控える）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 青色申告決算書の損益計算書と所得金額を確かめる (Priority: P1)

年度の仕訳を入れ終えた利用者は、決算書の画面で年度を選ぶ。画面は、帳簿から集計した青色申告決算書（一般用）1ページの損益計算書の各欄（売上、経費の各科目、任意科目、経費計、差引金額、青色申告特別控除前の所得金額、青色申告特別控除額、所得金額）を、欄番号と並べて示す。任意科目の欄には科目名が付く。青色申告特別控除額は、利用者が答えた要件の確認リストに沿って決まる。利用者は、確定申告書第一表の「事業所得」に転記する値を画面で確かめ、印刷または CSV で控えを残す。

**Why this priority**: 決算書の1ページ目と所得金額が、確定申告で最も使う値である。001 の損益計算書を、決算書の欄の形に並べ直して控除を加えるだけで、すぐに転記に使える。

**Independent Test**: 合成の仕訳（売上と数種類の経費、任意科目に当たる科目を含む）を入れた年度で決算書の画面を開き、各欄の値、経費計・差引金額・所得金額の計算、任意科目の科目名、控除額が期待どおりであり、CSV の値が画面と一致することを確かめる。

**Acceptance Scenarios**:

1. **Given** 売上と経費の仕訳がある年度, **When** 利用者が決算書の画面を開く, **Then** 損益計算書の各欄に、その欄に対応づいた科目の年間の金額（収益は貸方−借方、費用は借方−貸方）が表示され、経費計・差引金額・青色申告特別控除前の所得金額が計算される
2. **Given** 決算書の一般の欄に当たらない費用の科目（例: 会議費、新聞図書費）を使った年度, **When** 決算書を開く, **Then** その科目は任意科目の欄に科目名つきで表示される
3. **Given** 任意科目に当たる科目が、決算書の任意科目の欄の数より多い年度, **When** 決算書を開く, **Then** 欄に収まらないことが警告され、利用者は科目の欄の割り当て（どの科目を「雑費」にまとめるかなど）を見直せる
4. **Given** 控除前の所得が 65万円以上で、65万円の要件をすべて満たすと答えた年度, **When** 決算書を開く, **Then** 青色申告特別控除額は 65万円、所得金額は控除前の所得から 65万円を引いた額になる
5. **Given** 控除前の所得が 65万円より少ない年度, **When** 決算書を開く, **Then** 青色申告特別控除額は控除前の所得と同じ額になり、所得金額は 0 になる
6. **Given** 65万円の要件のうち「期限内の e-Tax 送信または優良な電子帳簿保存」を満たさないと答えた年度, **When** 決算書を開く, **Then** 控除の上限は 55万円になり、満たさない要件が示される
7. **Given** 仕入・給料賃金・専従者給与・貸倒引当金・利子割引料・税理士報酬の科目を使わない年度, **When** 決算書を出力する, **Then** その欄は 0（または空欄。利用者が選ぶ）で出力される
8. **Given** 決算書の画面, **When** 利用者が CSV を出力する, **Then** 欄番号・欄名・金額の各行が画面の値と一致する
9. **Given** 控除の要件にまだ答えていない年度, **When** 決算書を開く, **Then** 欄43 までは計算され、欄44・欄45 と第一表に転記する値は空欄で「要件の回答が必要」と示され、回答の画面へ進める
10. **Given** 任意科目の欄が足りないという警告, **When** 利用者が科目の画面で、ある科目の決算書の欄を「雑費（欄31）」に変える, **Then** 決算書でその科目の金額は雑費の欄に含まれ、警告が消える。欄の変更は履歴に残る

### User Story 2 - 家事按分を決算に反映する (Priority: P1)

自宅を事務所に使う利用者は、地代家賃（ほかに水道光熱費・通信費など）の事業専用割合と、その根拠（面積・時間など）を年度ごとに登録する。年度末に、システムは按分の対象の科目について「帳簿の金額・事業専用割合・事業分・家事分」を示し、家事分を事業主貸へ振り替える決算整理の仕訳の案を作る。利用者が案を確かめて登録すると、決算書の各欄は按分後の金額になる。地代家賃は、支払先・物件・本年中の賃借料・必要経費算入額を決算書2ページの内訳として出す。

**Why this priority**: 按分を反映しないと、経費と所得が誤り、決算書の値をそのまま転記できない。自宅兼事務所の利用者には毎年必要な処理である。

**Independent Test**: 合成の年度で地代家賃に事業専用割合を登録し、振替の仕訳の案の金額（家事分の円未満の扱いを含む）、登録後の決算書の地代家賃の欄、事業主貸の残高、地代家賃の内訳の値を確かめる。

**Acceptance Scenarios**:

1. **Given** 地代家賃の帳簿の金額が年間 1,200,000円の年度, **When** 利用者が事業専用割合 30%、根拠「床面積 15㎡／50㎡」を登録する, **Then** 事業分 360,000円・家事分 840,000円と、「事業主貸 840,000 / 地代家賃 840,000」の年度末日付の振替の仕訳の案が示される
2. **Given** 根拠のメモを空にした按分の登録, **When** 保存する, **Then** 保存できず、根拠の入力を求められる
3. **Given** 前の年度と事業専用割合を変えた登録, **When** 保存する, **Then** 変更の理由の入力を求められ、理由とともに年度ごとの履歴に残る
4. **Given** 振替の仕訳の案, **When** 利用者が登録する, **Then** 通常の仕訳として登録され、決算書の地代家賃の欄は 360,000円、事業主貸は 840,000円増える
5. **Given** 按分の振替の仕訳を登録した後に、地代家賃の仕訳が追加・訂正された年度, **When** 決算書を開く, **Then** 帳簿の金額と按分の登録から求めた家事分が、登録済みの振替と合わないことが警告され、振替の仕訳を直す案が示される
6. **Given** 地代家賃の内訳（支払先、物件、本年中の賃借料、必要経費算入額）を登録した年度, **When** 決算書の2ページを出力する, **Then** 内訳が表示され、必要経費算入額の合計が地代家賃の欄と一致しないときは警告される
7. **Given** 締め済みの年度, **When** 按分の振替の仕訳の案を登録しようとする, **Then** 001 の規則どおり拒否され、締めの解除が必要なことが示される

### User Story 3 - 少額減価償却資産を固定資産台帳に登録する (Priority: P2)

パソコンなどの備品を買った利用者は、固定資産台帳に資産名・取得年月日・取得価額・事業専用割合を登録し、償却の方法として「少額減価償却資産の特例（措置法28条の2）」を選ぶ。システムは、取得価額が基準額未満であることと、その年の合計が年間の上限以下であることを確かめ、取得年に取得価額×事業専用割合を必要経費に算入する減価償却の仕訳の案を作る。決算書3ページの「減価償却費の計算」に台帳の各資産が並び、合計が損益計算書の減価償却費の欄と一致する。

**Why this priority**: 資産を買った年だけに必要で、毎年ではない。ただし、使った年は決算書の減価償却費の欄と3ページの表に直接出る。

**Independent Test**: 合成の年度で少額減価償却資産を登録し、基準額・年間の上限の検査、償却の仕訳の案、決算書3ページの各列（取得価額、償却方法、本年分の償却費、事業専用割合、必要経費算入額、未償却残高）と、減価償却費の欄との一致を確かめる。

**Acceptance Scenarios**:

1. **Given** 年度, **When** 利用者が取得価額 200,000円、事業専用割合 100% の資産を少額減価償却資産の特例で登録する, **Then** 本年分の償却費 200,000円、必要経費算入額 200,000円、未償却残高 0円となり、減価償却の仕訳の案が示される
2. **Given** 取得価額が基準額（取得の日に適用される基準額）以上の資産, **When** 少額減価償却資産の特例を選ぶ, **Then** 登録できず、基準額と、特例を使えない理由が示される
3. **Given** その年に特例で登録した資産の取得価額の合計が年間の上限を超える登録, **When** 保存する, **Then** 上限を超えることが示され、保存できない
4. **Given** 事業専用割合 50% の資産, **When** 登録する, **Then** 本年分の償却費は取得価額の全額、必要経費算入額はその 50%（円未満切り捨て）となり、残りは事業主貸への振替として仕訳の案に含まれる
5. **Given** 取込んだ帳簿で、資産の購入がすでに費用（減価償却費など）として仕訳されている年度, **When** 利用者が台帳に資産を登録し、その仕訳を指定する, **Then** 新しい仕訳の案は作られず、決算書3ページの表には資産が載る
6. **Given** 定額法・定率法などの方法, **When** 償却の方法を選ぶ, **Then** この機能では選べない（少額減価償却資産の特例だけが選べる）

### User Story 4 - 貸借対照表と元入金の繰越を確かめる (Priority: P2)

決算書4ページの貸借対照表は、期首（1月1日）と期末（12月31日）の現金・預金・売掛金・未払金・繰延資産（開業費）・事業主貸・事業主借・元入金と、青色申告特別控除前の所得金額を並べる。前の年度の帳簿があれば、システムは「前の年度の元入金＋事業主借＋所得−事業主貸」と前の年度の期末の各残高から、今の年度の期首に来るべき値を求め、登録された期首残高と比べる。合わない科目があれば差額を示し、利用者は差の説明をメモに残す。資産の科目の残高が負のときや、繰延資産を償却せずに持ち続けているときも知らせる。

**Why this priority**: 期首と前期末の食い違いや負の売掛金は、申告の後に気づきにくい誤りである。決算書の4ページを出すたびに自動で確かめる。

**Independent Test**: 合成の2年度（前の年度に事業主貸・事業主借・所得がある）で、今の年度の期首残高を正しく登録した場合と、売掛金だけをずらして登録した場合を作り、貸借対照表の期首・期末、貸借の一致、元入金の繰越の検査、差額と説明メモの表示を確かめる。

**Acceptance Scenarios**:

1. **Given** 期首残高と仕訳がある年度, **When** 決算書の4ページを開く, **Then** 期首と期末の各科目の残高、資産合計と負債・資本合計が示され、両者が一致する。期末の資本の部に青色申告特別控除前の所得金額が表示される
2. **Given** 前の年度の帳簿と、前の年度の期末から正しく繰り越した期首残高, **When** 4ページを開く, **Then** 元入金の繰越の検査は「一致」と示される
3. **Given** 期首の売掛金を前の年度の期末と異なる額で登録した年度, **When** 4ページを開く, **Then** 売掛金と元入金について、前の年度の期末から求めた値・登録された期首の値・差額が警告として示される
4. **Given** 3 の警告, **When** 利用者が差の説明（例: 前の年度は12月の売上を未収に計上していなかった）を入力する, **Then** 説明は年度ごとに保存され、警告の横と出力に表示される。差額そのものは変わらない
5. **Given** 期末の売掛金の残高が負の年度, **When** 4ページを開く, **Then** 負の残高の科目が警告される（001 の FR-033 と同じ判定）
6. **Given** 開業費（繰延資産）の残高が期首と期末で同じ年度, **When** 4ページを開く, **Then** 繰延資産を償却するかどうかを検討するよう知らせる（償却の計算はしない）
7. **Given** 前の年度の帳簿がない年度（帳簿の最初の年度）, **When** 4ページを開く, **Then** 元入金の繰越の検査は「前の年度なし」と示され、警告は出ない

### User Story 5 - 月別売上と売上先の明細を出す (Priority: P2)

決算書2ページの月別売上と、3ページの売上先の明細を帳簿から作る。月別売上は、売上と雑収入を月ごとに集計する。売上先の明細は、売上の仕訳行の取引先ごとに年間の金額を集計し、金額の大きい順に様式の行数まで個別に、残りを「上記以外の売上先の計」にまとめる。どちらも合計が損益計算書の売上（欄1）と一致することを確かめる。利用者は「本年中における特殊事情」をメモに書ける。

**Why this priority**: 決算書の提出に必要な欄だが、帳簿から機械的に作れる。合計の不一致（取引先の付け漏れなど）を見つける効果が大きい。

**Independent Test**: 合成の年度で、取引先を付けた売上・付けない売上・雑収入・売上の訂正（借方の売上）を含めて、月別の金額、売上先の上位の並びと「上記以外」の集約、合計の一致の検査を確かめる。

**Acceptance Scenarios**:

1. **Given** 各月に売上がある年度, **When** 2ページを開く, **Then** 1〜12月の売上と雑収入、その合計が表示され、合計は欄1と一致する
2. **Given** 取引先が様式の行数より多い年度, **When** 3ページを開く, **Then** 金額の大きい順に様式の行数までの取引先が個別に、残りが「上記以外の売上先の計」として表示され、全体の合計が欄1と一致する
3. **Given** 取引先を付けていない売上の仕訳行がある年度, **When** 3ページを開く, **Then** その金額は「上記以外の売上先の計」に含まれ、取引先が付いていない売上の件数と金額が知らされる
4. **Given** 何らかの理由で売上先の合計が欄1と一致しない年度, **When** 3ページを開く, **Then** 差額が警告として示される
5. **Given** 利用者が特殊事情のメモを入力した年度, **When** 決算書を出力する, **Then** メモが該当の欄に出力される

### User Story 6 - 確定申告の控えを残す (Priority: P3)

申告の時期に、利用者は年度ごとに、事業所得以外の申告に使う金額（給与と源泉徴収税額、社会保険料、小規模企業共済・iDeCo、生命保険料、寄附金（ふるさと納税）、医療費、株式・暗号資産、外国税額控除など）と、その証明書のファイルの保管場所をメモとして登録する。システムはこれらを計算に使わない。あわせて、提出した決算書・申告書・添付書類のファイルの保管場所を年度ごとに記録する。

**Why this priority**: 申告に必要な情報を1か所にまとめる補助である。決算書の値には影響しない。

**Independent Test**: 合成の年度で、事業所得以外のメモと書類の保管場所を登録・編集・一覧し、保管場所のファイルが見つからないときの表示を確かめる。

**Acceptance Scenarios**:

1. **Given** 年度, **When** 利用者が「社会保険料」の金額と証明書のファイルの場所を登録する, **Then** 年度の控えの一覧に表示され、決算書の値は変わらない
2. **Given** 年度, **When** 利用者が提出した決算書の PDF の場所と提出日を登録する, **Then** 年度の書類の一覧に表示される
3. **Given** 登録した場所にファイルがない, **When** 一覧を開く, **Then** そのファイルが見つからないことが示される（登録は消えない）
4. **Given** 控えの一覧, **When** 利用者が年度を切り替える, **Then** その年度の控えだけが表示される

### User Story 7 - 免税事業者の取込で税区分の警告をまとめる (Priority: P3)

消費税の免税事業者の利用者が freee から取り込むと、税区分が科目と合わないことの警告（002 の TAX_CATEGORY_SUSPICIOUS）が大量に出る。免税の期間では税区分は帳簿の金額に影響しないため、システムは事業体の消費税の設定（001 の FR-009）を見て、免税の期間の仕訳ではこの警告を1件ずつ出さず、件数だけをまとめて示す。

**Why this priority**: 取込のプレビューを読みやすくする改善で、帳簿の値には影響しない。

**Independent Test**: 合成の freee のファイル（費用の科目に課税売上の税区分が付いた仕訳を含む）を、免税の期間の事業体と課税の期間の事業体で取り込み、プレビューの警告の出方を比べる。

**Acceptance Scenarios**:

1. **Given** 取り込む仕訳の日付が免税の期間, **When** プレビューを開く, **Then** 税区分の警告は1件ずつ出ず、「免税の期間のため税区分の警告を N 件まとめた」と1行で示され、利用者は開いて一覧を見られる
2. **Given** 取り込む仕訳の日付が課税の期間, **When** プレビューを開く, **Then** 税区分の警告は 002 と同じく1件ずつ示される
3. **Given** 年の途中で免税から課税に変わる事業体, **When** 両方の期間にまたがる仕訳を取り込む, **Then** 免税の期間の仕訳の警告だけがまとめられる

### Edge Cases

- 決算書の画面を開いた年度が締め前のとき: 値は表示するが「締め前（暫定）」と明示する。締め済みの年度でも表示・出力はできる
- 按分の対象の科目の帳簿の金額が 0 または負のとき: 振替の仕訳の案を作らず、理由を示す
- 家事分の計算で円未満が出るとき: 事業分（必要経費算入額）を円未満切り捨てとし、家事分は帳簿の金額から事業分を引いた額とする（合計が帳簿の金額と一致する）
- 事業専用割合が 100% のとき: 振替は作らない。0% のとき: 保存の前に「全額が家事分になり、この科目は経費になりません」と確認のダイアログを出し、利用者が了承したときだけ保存する
- 登録済みの按分の振替が、現在の帳簿から求めた家事分より多いとき（振替の後に費用の仕訳が取り消された場合など）: 差額を戻す逆向きの仕訳（費用の科目 / 事業主貸）を案として示す
- 決算書の様式がない年度（令和7年分より前など）を開いたとき: その年度以前で最も新しい様式（なければ最も古い様式）を使い、使った様式の年分を画面に示す
- 期首残高に事業主貸・事業主借の残高が登録されているとき（前の年度から繰り越していない場合）: 4ページの期首にその金額を表示し、元入金への繰り込みを促す（様式では通常、期首は空欄）
- 按分の対象に費用以外の科目を選んだとき、資産の勘定に資産以外の科目を選んだとき: 保存できず、選べる科目の区分を示す
- 按分の振替を登録した後に按分の割合を変えたとき: 登録済みの振替と合わないことを警告し、001 の訂正（理由つき）で直す案を示す
- 少額減価償却資産を取得した年度が締め済みのとき: 台帳への登録はできるが、仕訳の案は登録できない（001 の規則）
- 少額減価償却資産の基準額や年間の上限が、取得の日の時点で適用されないとき（特例の適用期限を過ぎたとき）: 特例を選べず、適用期間を示す
- 売上先の取引先の名前が同じで別の取引先として登録されているとき: 別の行として集計し、名前が重複していることを知らせる
- 売上の科目に借方の行（値引き・返品・訂正）があるとき: 月別・売上先とも、貸方−借方の差し引きで集計する
- 元入金の繰越の検査で、前の年度が締められていないとき: 検査は行い、前の年度が締め前であることを示す
- 青色申告特別控除前の所得が 0 以下のとき: 控除額は 0、所得金額は控除前の所得のまま（損失）とする
- 事業体の種別が法人のとき: 決算書の画面は使えない（個人の青色申告決算書だけを扱う）
- 控えや書類の保管場所に、データの場所（`data/`）や作業の場所（`work/`）の中のパスが登録されたとき: 登録はできる（パスを記録するだけで、ファイルの中身は読まない）

## Requirements *(mandatory)*

### Functional Requirements

**決算書（共通）**

- **FR-001**: システムは MUST、個人の事業体の年度ごとに、青色申告決算書（一般用）の1〜4ページの各欄の値を帳簿の仕訳と期首残高から導出して表示する。決算書の値を独立して保存・編集させない（001 の FR-031）
- **FR-002**: システムは MUST、決算書の画面で、年度が締め前か締め済みかを示す
- **FR-003**: システムは MUST、決算書を印刷用の体裁（A4）と CSV（欄番号・欄名・金額）で出力でき、出力の値は画面と一致する
- **FR-004**: システムは MUST、確定申告書第一表の「事業所得（営業等）」に転記する値（所得金額、欄45）と、青色申告特別控除額を、決算書の画面の先頭（1ページの表より上）に、ほかの欄と区別して示す

**損益計算書（1ページ）**

- **FR-005**: システムは MUST、勘定科目に対応づいた決算書の欄番号（001 の FR-004）に沿って、損益計算書の各欄を集計する。収益の科目は貸方−借方、費用の科目は借方−貸方の年間の合計とする
- **FR-006**: システムは MUST、一般の欄に当たらない費用の科目を任意科目の欄に科目名つきで出力する。任意科目に当たる科目が欄の数を超えるときは警告する。利用者は MUST、科目の画面で費用の科目の決算書の欄番号（一般の欄、任意欄、雑費）を変えられ、変更は履歴に残る
- **FR-007**: システムは MUST、経費計、差引金額、青色申告特別控除前の所得金額、所得金額を計算し、経費計と差引金額が帳簿の損益計算書（001 の FR-029）の費用合計・利益と一致することを確かめ、一致しないときは警告する
- **FR-008**: 利用者は MUST、表示と出力（印刷・CSV）のたびに、使わない欄を 0 で出すか空欄で出すかを選べる（選択は保存しない。既定は 0）

**青色申告特別控除**

- **FR-009**: システムは MUST、青色申告特別控除額を「控除の上限額と青色申告特別控除前の所得金額のいずれか少ない方（所得が 0 以下なら 0）」として、決算書2ページの青色申告特別控除額の計算の欄の形で示す
- **FR-010**: システムは MUST、控除の上限額（65万円・55万円・10万円）を、利用者が年度ごとに答える要件の確認リスト（正規の簿記の原則による記帳、貸借対照表と損益計算書の添付、期限内の申告、e-Tax による送信または優良な電子帳簿の保存）から決める。満たさない要件と、その結果の上限額を示す
- **FR-011**: システムは MUST、控除の上限額と要件を、適用開始日と出典つきの税制のデータとして持つ（Constitution VI）

**家事按分**

- **FR-012**: 利用者は MUST、年度ごとに、費用の科目（補助科目の指定も可）ごとに事業専用割合（0〜100%）と根拠のメモを登録できる。根拠のメモは必須とする。対象は区分が費用の科目に限る
- **FR-013**: システムは MUST、前の年度と事業専用割合を変えるとき、変更の理由を必須とし、按分の登録の変更を履歴として残す
- **FR-014**: システムは MUST、按分の対象の科目ごとに、帳簿の金額・事業専用割合・事業分（円未満切り捨て）・家事分（帳簿の金額−事業分）を示し、家事分を事業主貸へ振り替える年度末日付の仕訳の案を作る
- **FR-015**: システムは MUST、按分の振替の仕訳の案を利用者が確かめてから、001 の仕訳の登録の規則（締め済みの年度の拒否など）で登録する。按分の振替の仕訳は按分の登録への参照を持ち、どの年度・科目の按分かをたどれる
- **FR-016**: システムは MUST、登録済みの按分の振替の金額が、現在の帳簿の金額と按分の登録から求めた家事分と合わないとき、決算書の画面で警告し、差を直す案を示す
- **FR-017**: 利用者は MUST、年度ごとに地代家賃の内訳（支払先の住所・氏名、賃借物件、本年中の賃借料・権利金等、必要経費算入額）を登録できる。システムは MUST、必要経費算入額の合計が損益計算書の地代家賃の欄と一致しないときに警告する

**固定資産台帳と減価償却**

- **FR-018**: 利用者は MUST、固定資産台帳に資産（名称、数量、取得年月日、取得価額、償却の方法、耐用年数、事業専用割合、摘要）を登録・編集・除却できる。資産の勘定は区分が資産の科目に限る。登録の変更は履歴に残す
- **FR-019**: システムは MUST、償却の方法として、この機能では「少額減価償却資産の特例（措置法28条の2）」だけを提供する。方法の一覧はデータとして持ち、後から定額法・定率法などを加えられる形にする
- **FR-020**: システムは MUST、少額減価償却資産の特例で、取得価額が取得の日に適用される基準額未満であること、その年に特例を使う資産の取得価額の合計が年間の上限以下であることを確かめ、満たさない登録を拒否する。基準額・年間の上限・適用期間は、適用開始日と出典つきの税制のデータとして持つ（Constitution VI）
- **FR-021**: システムは MUST、少額減価償却資産について、取得年の本年分の償却費（取得価額の全額）、必要経費算入額（償却費×事業専用割合、円未満切り捨て）、未償却残高（0）を計算し、減価償却の仕訳の案（家事分は事業主貸への振替を含む）を作る。案の登録は FR-015 と同じ規則とする
- **FR-022**: 利用者は MUST、資産の取得がすでに仕訳されている場合（取込んだ帳簿など）、台帳の資産にその仕訳を結びつけられる。結びつけた資産について、システムは新しい仕訳の案を作らない
- **FR-023**: システムは MUST、決算書3ページの「減価償却費の計算」に台帳の資産を並べ、本年分の必要経費算入額の合計が損益計算書の減価償却費の欄と一致しないときに警告する

**月別売上と売上先（2・3ページ）**

- **FR-024**: システムは MUST、売上の科目と雑収入の科目を月ごとに集計し（貸方−借方）、年間の合計が欄1と一致することを確かめる
- **FR-025**: システムは MUST、売上の仕訳行を取引先ごとに集計し、金額の大きい順に様式の行数まで個別に、残り（取引先のない行を含む）を「上記以外の売上先の計」にまとめる。様式の行数はデータとして持つ
- **FR-026**: システムは MUST、売上先の合計が欄1と一致しないとき差額を警告し、取引先が付いていない売上の行の件数と金額を示す
- **FR-027**: 利用者は MUST、年度ごとに「本年中における特殊事情」のメモを登録でき、決算書の出力に含まれる

**貸借対照表（4ページ）と元入金の繰越**

- **FR-028**: システムは MUST、期首と期末の貸借対照表を決算書の科目順で示し、資産合計と負債・資本合計の一致を確かめる。期末の資本の部に青色申告特別控除前の所得金額を示す
- **FR-029**: システムは MUST、前の年度の帳簿がある場合、前の年度の期末の残高と「元入金＋事業主借＋所得−事業主貸」から今の年度の期首に来るべき値を求め、登録された期首残高と科目ごとに比べ、差がある科目と差額を警告する（002 の FR-020a と同じ求め方）
- **FR-030**: 利用者は MUST、FR-029 の差について、年度ごとに説明のメモを登録できる。説明は警告とともに表示・出力される。説明を登録しても差額の計算は変わらない
- **FR-031**: システムは MUST、資産の科目の残高が負のとき（001 の FR-033）と、繰延資産の残高が期首と期末で変わらないときに、決算書の画面で知らせる。繰延資産の償却の計算はしない
- **FR-032**: システムは MUST、事業用の口座を使わず事業主貸・事業主借に収支が集まる帳簿でも、事業用の口座を使う帳簿でも、同じ規則で貸借対照表と元入金の繰越を求める（両方の形の帳簿でテストする）

**確定申告の控え**

- **FR-033**: 利用者は MUST、年度ごとに、事業所得以外の申告に使う項目（種類、金額、証明書のファイルの場所（絶対パス）、メモ）を登録・編集・削除できる。種類は一覧（給与・源泉徴収、社会保険料、小規模企業共済等掛金、生命保険料、地震保険料、寄附金、医療費、株式等、暗号資産、外国税額控除、その他）から選ぶ
- **FR-034**: システムは MUST、FR-033 の項目を決算書や所得の計算に使わない
- **FR-035**: 利用者は MUST、年度ごとに、提出した書類（決算書、申告書、添付書類など）の種類、ファイルの場所（絶対パス）、提出日、メモを登録・編集・削除できる。システムはファイルの中身を読まず、コピーもしない
- **FR-036**: システムは MUST、FR-033・FR-035 で登録したファイルの場所にファイルがあるかを一覧で示す

**免税事業者の取込の警告**

- **FR-037**: システムは MUST、freee の取込のプレビューで、仕訳の日付が事業体の消費税の設定（001 の FR-009）の免税の期間に当たるとき、税区分の警告（TAX_CATEGORY_SUSPICIOUS）を1件ずつ出さず、件数をまとめた1件の情報として示す。利用者はまとめた警告の一覧を開ける。課税の期間の仕訳は 002 と同じく1件ずつ警告する

**実データでの照合**

- **FR-038**: システムは MUST、決算書の各欄の値を、実データ（`work/`）の帳簿から作り、過去の青色申告決算書の値と照合するためのローカル専用の手段を持つ。照合の結果はリポジトリに含めない（Constitution III）

### Key Entities *(include if feature involves data)*

- **決算書**: 事業体・年度ごとに帳簿から導出する青色申告決算書（一般用）の各欄の値。保存しない。損益計算書（1ページ）、月別売上・地代家賃の内訳・青色申告特別控除額の計算（2ページ）、売上先の明細・減価償却費の計算（3ページ）、貸借対照表（4ページ）からなる
- **決算書の様式**: 欄番号、欄名、ページ、一般の欄か任意科目の欄か、売上先の明細の行数など、決算書の形を表すデータ。年分ごとの違いに備えて適用年分を持つ
- **家事按分の登録**: 事業体・年度・科目（補助科目）ごとの事業専用割合、根拠のメモ、変更の理由と履歴
- **決算整理の仕訳**: 按分の振替や減価償却のために、システムが案を作り利用者が登録した仕訳。001 の通常の仕訳であり、作った元（按分の登録、台帳の資産）への参照を持つ
- **地代家賃の内訳**: 事業体・年度ごとの支払先、物件、本年中の賃借料、必要経費算入額
- **固定資産**: 名称、数量、取得年月日、取得価額、償却の方法、耐用年数、事業専用割合、摘要、除却の状態、結びつけた仕訳。変更の履歴を持つ
- **税制のデータ（決算）**: 少額減価償却資産の基準額・年間の上限・適用期間、青色申告特別控除の上限額と要件。適用開始日と出典を持つ
- **青色申告特別控除の要件の回答**: 事業体・年度ごとの、要件の確認リストへの回答
- **決算のメモ**: 事業体・年度ごとの特殊事情、期首と前期末の差の説明
- **申告の控え**: 事業体・年度ごとの事業所得以外の項目（種類、金額、ファイルの場所、メモ）
- **提出書類の記録**: 事業体・年度ごとの書類の種類、ファイルの場所、提出日、メモ

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 2025年分の帳簿（002 で取り込んだもの）に、家事按分・少額減価償却資産・控除の要件を登録したとき、決算書1〜4ページの金額の欄が、2025年分の青色申告決算書（R7）の値とすべて一致する（実データでの照合。結果はリポジトリに含めない）
- **SC-002**: 2024年分と2025年分を続けて取り込んだ帳簿で、2024年の期末の売掛金の負の残高が警告され、2025年の期首と2024年の期末の食い違い（売掛金・未払金・元入金）が科目ごとの差額とともに検知される
- **SC-003**: 無作為に生成した年度の帳簿で、決算書の経費計・差引金額・所得金額が帳簿の損益計算書と常に一致し、4ページの資産合計と負債・資本合計が常に一致する（不一致0件）
- **SC-004**: 無作為に生成した按分の登録（割合 0〜100%）で、事業分と家事分の合計が常に帳簿の金額と一致し、振替を登録した後の帳簿の貸借が常に一致する
- **SC-005**: 仕訳を入れ終えた年度で、按分と資産の登録から決算書の値を e-Tax に転記できる状態まで、利用者が30分以内に終えられる（quickstart の手動確認で時間を計る）
- **SC-006**: 1年分（約500仕訳）の帳簿で、決算書の画面を開いてから全ページの値が表示されるまで2秒以内
- **SC-007**: 免税の期間の帳簿を取り込むとき、プレビューの税区分の警告が1件にまとまり、課税の期間の仕訳の警告の件数は 002 と変わらない

## Assumptions

- 対象は個人事業の青色申告決算書（一般用）だけとする。不動産所得用・農業所得用・現金主義用、収支内訳書（白色申告）、法人の決算は範囲外
- 決算書の値は画面・印刷・CSV で示し、e-Tax には利用者が手で転記する。e-Tax の取込形式（XML / CSV）の出力は範囲外（利用者の確認, 2026-10-19）
- 減価償却は少額減価償却資産の特例だけを実装する。定額法・定率法、一括償却資産、特例の基準額の改正（個人への適用は要確認）は、データと方法の一覧を足せば加えられる形にとどめる（利用者の確認, 2026-10-19）
- 家事按分と減価償却は、決算書の出力だけで調整せず、決算整理の仕訳として帳簿に登録する（Constitution I: 帳票は仕訳から導出する。docs/requirements.md FR-04「私用分は事業主貸へ自動で振り替える」）。仕訳は案として示し、利用者が登録する
- 取り込んだ帳簿で按分や償却がすでに仕訳になっている場合に備え、資産は既存の仕訳と結びつけられ（FR-022）、按分は登録済みの振替との差を警告する（FR-016）。帳簿の地代家賃がすでに按分後の金額の場合、利用者は按分を登録せず、地代家賃の内訳（FR-017）だけを登録する
- 青色申告特別控除は、要件を利用者が回答する方式とし、e-Tax の送信の事実や電子帳簿の届出をシステムで確かめない
- 消費税の課税区分は 001 の消費税の設定（FR-009）をそのまま使い、新しい設定を足さない
- 決算書の様式は令和7年分を基準にする。様式の年分ごとの違いは決算書の様式のデータで扱う
- 前年比較の表示は範囲外とする（001 の FR-030 で損益計算書・貸借対照表の前年比較はできる）（利用者の確認, 2026-10-19）
