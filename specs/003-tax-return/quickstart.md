## 2. 手動での確認（合成のデータ）

```bash
TREBUCHET_DATA_DIR="$PWD/.tmp/quickstart-003" pnpm dev   # http://127.0.0.1:5173
```

1. **準備**: 個人の事業体を開始年度「2024」で作り、2024年度と2025年度を用意する。002 のフィクスチャ（`packages/domain/test/fixtures/freee/`）を取り込むか、売上（取引先つき・なし）、地代家賃、会議費などの任意科目、雑収入の仕訳を手で入れる
2. **損益計算書（US1）**: 「決算書」で 2025 を開く → 1ページの各欄、任意科目の科目名、経費計・差引金額が 001 の損益計算書と一致する。「締め前（暫定）」と表示される。控除の要件に答える前は「要件の回答が必要」と出る
3. **控除（US1）**: 要件にすべて「はい」→ 控除 65万円（控除前の所得が 65万円以上のとき）。e-Tax と電子帳簿を「いいえ」→ 55万円と、満たさない要件が出る。第一表に転記する値（欄45）が目立つ位置にある
4. **家事按分（US2）**: 地代家賃に割合と根拠を登録 → 事業分・家事分と振替の案が出る → 登録 → 地代家賃の欄が事業分になり、事業主貸が増える。地代家賃の仕訳を1件足す → 振替が古いことの警告と差額の案が出る。根拠を空にすると保存できない
5. **少額減価償却資産（US3）**: 基準額未満の資産を登録 → 償却の案 → 登録 → 3ページの表と欄18が一致する。基準額以上の資産は登録できない
6. **貸借対照表（US4）**: 2024年度に事業主貸・事業主借・売上を入れ、2025年度の期首を正しく繰り越す → 「一致」。期首の売掛金をずらす → 売掛金・元入金の差額の警告 → 説明を入れると警告の横に出る。売掛金が負の年度は負の残高の警告が出る
7. **月別売上と売上先（US5）**: 月別の計と売上先の合計が欄1と一致する。取引先なしの売上が「上記以外」に入り、件数と金額が知らされる
8. **控え（US6）**: 社会保険料の金額と `.tmp/` の下の実在のファイルのパスを登録 → 一覧で「あり」。存在しないパス → 「見つからない」
9. **免税の期間（US7）**: 免税の事業体で、費用に課税売上の税区分が付いたフィクスチャを取込のプレビューに出す → 税区分の警告が1件にまとまる
10. **出力**: CSV の値が画面と一致する。ブラウザの印刷で A4 の4ページに分かれる

確認が終わったら `pnpm dev` を止め、`.tmp/quickstart-003/` を削除する。

## 3. 実データでの照合（ローカル専用）

SC-001・SC-002 を確かめる。出力と実データの数値はリポジトリに含めない（research R15）。

```bash
node scripts/verify-tax-return.ts \
  --journal work/<2025年分の仕訳帳>.csv --ledger work/<2025年分の総勘定元帳>.csv \
  --year 2025 --closing work/tax-return-2025.json [--mapping .tmp/<対応表>.json]
```

- `work/tax-return-2025.json`（利用者が手で作る。形はスクリプトの先頭のコメント）に、按分・資産・控除の回答と、R7 の決算書の欄の値を書く
- 1〜4ページの金額の欄が R7 とすべて一致する（SC-001）
- 2024年分を先に取り込み（`--keep`）、2025年分を `--continue` で足したとき、2024年末の負の売掛金と、2025年の期首と 2024年の期末の食い違い（売掛金・未払金・元入金）が警告に出る（SC-002）
