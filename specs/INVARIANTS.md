# 不変条件の索引（INV-1〜39）

不変条件の番号は機能をまたいで通し番号。**正本は各機能の `data-model.md` §4**（検証の手段もそこにある）。この表は索引で、説明は一行に要約している。食い違いがあれば `data-model.md` が正しい。テストは fast-check の性質テストか統合テスト（[AGENTS.md](../AGENTS.md)「開発の進め方」）。

## 001 帳簿コア（INV-1〜10）— [data-model §4](001-ledger-core/data-model.md)

| INV | 内容 |
|---|---|
| INV-1 | 有効な仕訳ごとに Σ借方 = Σ貸方 |
| INV-2 | 各仕訳は借方行・貸方行を 1 行以上ずつ持つ |
| INV-3 | 金額は 0 < amount < 10^12 の整数 |
| INV-4 | 試算表の借方合計 = 貸方合計 |
| INV-5 | 資産 = 負債 + 純資産 + 当期利益 |
| INV-6 | 取消済みの仕訳は集計に影響しない |
| INV-7 | 締め済み年度の仕訳は変更されない |
| INV-8 | 仕訳番号は単調増加で重複しない |
| INV-9 | audit_log は追記のみ |
| INV-10 | 内税額 = floor(税込額 × 税率 / (100 + 税率))。税率は仕訳の日付で決まる |

## 002 freee の取込（INV-11〜17）— [data-model §4](002-freee-import/data-model.md)

| INV | 内容 |
|---|---|
| INV-11 | 取込は全部か無か（途中で失敗したら取込の前と同じ） |
| INV-12 | 取り消されていない参照の中で freee の仕訳 ID は一意（再取込で仕訳は増えない） |
| INV-13 | 取り込んだ仕訳は INV-1〜3・7・10 を満たす |
| INV-14 | freee 形式を生成して取り込むと、照合のすべての行が一致する |
| INV-15 | 取込の取消の後、帳票の金額は取込の前と同じ。取消された仕訳はすべて `voided` で理由がある |
| INV-16 | 期首残高の案は貸借が一致する |
| INV-17 | `parse(toCsv(rows)) = rows`（CSV の往復） |

## 003 決算書（INV-18〜24）— [data-model §4](003-tax-return/data-model.md)

| INV | 内容 |
|---|---|
| INV-18 | 決算書の経費計・差引金額は、001 の損益計算書の費用合計・利益に等しい |
| INV-19 | 決算書 4 ページの期首・期末とも、資産合計 = 負債・資本合計 |
| INV-20 | 按分で、0 ≤ 事業分 ≤ 帳簿の金額、事業分 + 家事分 = 帳簿の金額 |
| INV-21 | 少額減価償却資産の特例は、取得価額の基準額と年間の上限を超えない |
| INV-22 | 青色申告特別控除額 = min(上限額, max(0, 欄43)) |
| INV-23 | 決算整理の仕訳の案は貸借が一致し、行の金額 > 0、日付は年度末日 |
| INV-24 | 月別売上の合計 = 欄 1 = 売上先の明細の合計 |

## 004 認証とバックアップ（INV-25〜29）— [data-model §4](004-auth-backup/data-model.md)

| INV | 内容 |
|---|---|
| INV-25 | `restore(backup(data, pass), pass)` の後、除外する表を除いて全表の内容が元と一致する |
| INV-26 | バックアップの 1 バイトの変更・切り詰め・誤ったパスフレーズは、復号で必ず失敗する |
| INV-27 | `selectBackupsToPrune` は、この Mac の古いファイルだけを選び、残すべきファイルを選ばない |
| INV-28 | セッションは、失効済みか期限切れなら必ず無効 |
| INV-29 | 公開の手続きの一覧以外の `/api` のルートは、有効なセッションがなければ 401 |

## 005 請求と定期仕訳（INV-30〜39）— [data-model §4](005-recurring-invoicing/data-model.md)

| INV | 内容 |
|---|---|
| INV-30 | 請求書の total = Σ明細 = 売上の仕訳の金額。税額は税率ごとの内税の式に従う |
| INV-31 | 事業体の中で seq・請求番号は重複せず、発行の順に増え、取消した番号は再使用されない |
| INV-32 | 発行・消し込み・取消は全部か無か（請求書 ⇔ 仕訳の対応が保たれる） |
| INV-33 | 消し込みの充当額の合計 ≤ total。状態は残額だけで決まる |
| INV-34 | 取引先ごとの請求・入金に結びつく仕訳の売掛金残高 = 取消でない請求書の残額の合計 |
| INV-35 | 定期仕訳は（定義, 月）ごとに高々 1 件登録され、判定の漏れがない |
| INV-36 | `clampDay` と `dueDate` は常にその月の範囲に収まる |
| INV-37 | 明細の金額と別記の税額の計算は整数で、小計 + 税額 = 税込の合計 |
| INV-38 | 発行済みの請求書の写しは、設定・取引先・条件・工数のどんな変更の後も変わらない |
| INV-39 | `source` が `invoice`・`payment` の仕訳は、請求・入金の取消以外では訂正・取消されない |
